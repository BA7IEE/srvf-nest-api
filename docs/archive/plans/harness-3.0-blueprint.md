## 一、结论

Harness 2.0 的骨架(拍板主权、机器守护、行为锁、风险分级)保留;其「肉」(恒读散文、手写镜像、串行验证链、人肉编排)是为 2025 弱模型设计的补偿,已从保护变成主要成本。Harness 3.0 = **投递方式革命:规则语义零放宽,执法从「模型自觉读散文」搬到「机器强制 + 独立核验」**,维护者退出验证环,只保留提需求、拍板、读简报三个角色。

## 二、证据摘要(数字可溯源至 artifact 附录)

- 本地全量检查 + CI 占正常样本墙钟 **55–61%**;CI 固定 ~25.5 分钟,e2e 占 85%,与 PR 大小弱相关;48 次本地全量 e2e 中 20 次纯重复;8/30 PR 候选冻结过晚;11/30 整套重跑(粒度过粗);3 个异常长尾样本占总墙钟 32%。
- 恒读税:每会话 1.5–2.5 万 token,每 lane/fork 重付;簿记税:抽样会话 45% 文件编辑为文档镜像,发版 = 5–6 个簿记 PR;权限税:50 次拒绝中 20% 为分类器误伤;等待税:单会话 CI 轮询最高 64 次,另一会话纯等待 2.31 小时。
- 知识层 562KB 中约 50% 为代码/测试真相的手写镜像,仅 ~30%(决策锁/不做清单/运维态/业务拍板)不可重建。
- 行业公约数:Anthropic 为 Claude 5 代删掉系统提示 80%+ 无评测损失;AGENTS.md 应为 ~100 行地图;Context ≠ enforcement;镜像反转;Generator/Evaluator 分离;每模型代际重审 harness;20–50 个真实事故场景起步建回归集。

## 三、五公理

1. **语义零放宽,执法全机器化**:「必须/绝不」落为权限规则/hook/lint/结构测试/CI;散文只留判断型原则与 why。
2. **单一权威源,其余皆生成**:派生视图由脚本生成,CI 强制新鲜度;「检测漂移」被「消灭副本」取代。
3. **机器可查的事实不入文档**:人工只维护拍板决策(含 why)、不做清单、现实运维态三类真资产。
4. **人只在意图与拍板出现**:简报结论机器复制自核验产物与 CI 状态,附可点击链接;人永不充当验证环。
5. **Harness 自身可回归**:事故 → 可回放场景集(含反向案例);守卫必附自测;每模型代际重审;复杂度须可度量证明收益。

## 四、七刀方案(要点)

**刀壹·验证链**:e2e per-worker 派生库并行(28m→≤8m;处理 detectOpenHandles/连接池/共享存储目录三坑,留 flake 观察期);CI 拆 fast/slow(25m→10–14m);本地 full 保留为 push 前闸门、CI 为合并唯一权威(「只跑定向」仅限 docs-only 与琐碎小改);候选冻结纪律;失败定点重试 + flaky 隔离;quick 用 eslint 缓存+并行(~40s,不换 oxlint);长尾治理(环境 runbook + CI 绿后自动收尾)。

**刀贰·恒读层**:AGENTS.md 3.0 ≈100 行地图;铁律**三分类**(机器化/路径注入/留散文——敏感字段三问、characterization 先行、防枚举、不缓存、事务纪律、不顺手修等判断型规则留散文),逐条对照表随 PR;current-state 逐行处置(运维态行保留);readtax 保留改预算;去咆哮化;读取协议只写一份;V2 红线考古归档;缓存前缀纪律(harness 规则变更走独立小 PR、会话边界生效)。

**刀叁·执法迁移**:「规则 × 执法载体 × 执行体」全量矩阵(P0 交付物;Codex 只读 AGENTS.md,每条「绝不」须有 agent 无关载体:守护脚本包装/随仓 git hooks/CI/branch protection;Codex 侧用目录级 AGENTS.md);Claude 侧 PreToolUse + deny 双保险,hooks 文件自身入红区;开工门禁双件套(SessionStart 写通行标记 + PreToolUse 校验);定制 lint(报错即修复指引);写集 CI 核对;squash 八条 → 一条守护脚本;守卫自测并入常规测试。

**刀肆·镜像反转**:RBAC 地图运行时生成(派生库跑 seed 后 dump 矩阵);CODEMAP 生成 + 每模块一行人工;生成视图入 git + CI 强制新鲜度(regenerate-and-diff);counts 退役;NEXT_TASKS 迁 Issues;changelog.d 换**轻量行为变更 fragment**(行为差一句话 + FE 是否需适配,发版脚本聚合);发版两段式一键化(阶段 A 簿记 PR 等拍板合并,阶段 B 合并后 tag+Release+回填;幂等、fail-closed、自合门保留);handoff 瘦身(行为语义下沉 OpenAPI,自动契约 diff 人话摘要,保留轴模型/反模式/gap-ledger);OpenAPI 快照脱离 dev server;维护者速查页(高频问题 → 免命令点击路径)。

**刀伍·知识层**:决策锁结构化登记簿(id/日期/状态/取代/scope globs/锁文/why),按路径自动注入;reference 拆 what(删或指向测试)/why(并入决策记录);skills 去铁律复读、留真流程知识;模块级 CLAUDE.md 不留半覆盖中间态。

**刀陆·编排**:goal 三件套(spec/plan/progress,DoD 全为可执行命令,附验证盲区清单);访谈→SPEC→fresh 会话执行;lane 收敛为四不变式(写集互斥/schema 串行/串行集成/唯一简报流);废除可见窗口公理改受控试点(单 goal 后台 + 完整产物链复盘);后台执行体机器限额(墙钟/CI 轮次/同一失败重试 ≤2 自动挂起);简报管道规则(PASS/FAIL 机器复制 + 可点击链接,编排者无权改写);授权矩阵化 + 批量异步拍板;权限白名单按真实频次重生成(never-allow 语义机械继承)。

**刀柒·质检**:独立核验者常态化(C 档以上;**C/D 跨模型评审强制**,同模型仅附加层;范围限定正确性/既定需求);埋雷 PR 考核核验者;回归场景集 20–50 个(含「不该停时不停」反向案例);定期熵清理;返工=harness bug 制度;模型代际审计;新机器层自身设复杂度预算+自测纪律。

## 五、评审补上的三洞(P6 硬前置)

1. **考卷保护**:CI 检测对既有测试断言/contract snapshot/EXPECTED_ROUTES 的修改,须 PR body 结构化「行为变更声明」逐条对应,缺失即红;触碰既有断言强制跨模型评审。
2. **裁判保护**:scripts/**、test/setup/**、快照工具链入红区;CI 元检查:守卫/测试基建文件出现在 diff → 需维护者拍板标签,无标签即红;守卫改动强制跨模型评审。
3. **双模型执法矩阵**:每条「绝不」规则至少一个 agent 无关载体;高危档任务不派给无拦截约束的执行体。

## 六、保留清单

拍板主权与「按推荐」· 人话简报三行格式 · 「本次未做」段 · 决策锁概念 · 不可逆操作降速(migrate reset 恒需实时同意)· branch protection + merge-on-green · e2e 行为锁 + contract snapshot · 写集声明 · worktree + 派生库隔离 · fail-closed 纪律与自解释头注 · never-allow 防篡改头注 · 跨模型互查公理 A5 · 不做清单 · goal = 立项+授权 · docs-only CI 快速路径。业务决策锁一条不动,只换存放形态;重开的仅限 harness 流程锁(可见窗口公理 A4、恒读协议),已随本蓝图拍板。

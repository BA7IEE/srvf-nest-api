新加一个绕过 `runReplaceSet()` 的写入口不会有任何症状。故同刀接上一条**禁止型**不变量:

> 凡能到达唯一写原语 `replaceRolePermissionSet()` 的方法,**都必须**能到达 `assertStepUpProofOrThrow()`。

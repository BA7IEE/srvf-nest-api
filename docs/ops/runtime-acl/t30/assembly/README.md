# 常规单场次候选装配草案

执行只读预检用 `sh preflight.sh`。输出顺序为责任制、创建控制面、V1.1、外发条件、active schemaVersion>=3 且有 family 的模板数、创建权限码行数。数目通过仍须验证模板结构及普通主体有效范围。当前结果禁止声称候选已具备此流程。

可执行隔离对照使用相邻 t30/lab.ts、run.py，详见主报告。候选装配需另审。最小试运行单元是一支测试组织、一名正式成员发起人、一名独立组织范围发布审核人、一份经业务确认的单场次单默认岗位模板版本及其引用。沿正式目录与组织绑定流程提供 activity.create.record；保留创建人和审核人分离。模板已声明无需指标时不要求用户补填。安装先验证目标模板 hash、创建目录、scope、同源客户端与试运行人群约束。无精确目标模板或批准受众即停止。禁止用实验夹具填候选。

若另获批准，以 off 为回退基线，小范围试运行才选择 shadow。生产/smoke 的 active 要求 V1.1=true，超出本卡。shadow 对所有后端请求生效，前端受众控制不能代替 API 授权。停止试运行先阻断新建、停消费并确认无在途租约，按装配前快照恢复 off 并验证 20163。仅撤新授范围、停用专用主体和模板，保留历史引用、审计与回执；逐项核销 outbox。已有 T26b restore.sh 只负责恢复责任制，不能作为 V3 控制面的回滚。此包没有候选写入口。公网应用及恢复演习 NOT_RUN。

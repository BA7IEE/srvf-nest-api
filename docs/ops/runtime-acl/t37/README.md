## 故障和修复

审核详情原先只返回指标集指针，组织审核人通过这个指针无法看到实际指标。新版详情在原有申请范围判权之后，从**这份申请**的冻结基线和目标中解析引用。后端复用版本、集合与逐项定义的内容摘要校验，只返回匹配的定义。前端再次校验摘要、版本及内容完整性，在打开申请和确认批准时分别读取。无需目录维护权限。

原 #1416 兼容入口会写 schema V1 目标快照，缺少冻结的变更前值。实机第一次接入该入口时，审核页按设计拒绝批准，标记发起人正常撤回，历史记录保留。最终页面使用现成的 `/api/app/v1/my/managed-activities/:id/change-reviews` 写入完整 V7 申请，当前支持可完整比较的单项标题变更。审核页比对冻结的全部基线字段，保留未知内容、其他变更类型及受众限定的保护。新接口不要求增加业务角色。前端 #171 负责结算工作台，未改动该 PR。初次定位折叠区命中了隐藏文本，调整测试定位并复用原活动复测。

标记普通 USER 正常登录、临时组织成员关系读回后，公网创建训练草稿由此前 503/20036 进入 500/50000。期望 201 的断言 exit 1。PG 同时间窗记录 permission denied for table Activity 和含 26 个目标列、RETURNING id 的 INSERT。未保存逐请求双端 ID。归属结束、登出和账号禁用均 200/0。活动未创建，#1416 已发布活动及 #1417 结算更正对象正向 NOT_RUN。

候选角色的 Activity 读取已存在，INSERT 基线为零。grant-proposed.sql 与 rollback-proposed.sql 精确覆盖本条 SQL 的 26 列，须在实施同一事务核定基线后才能采用。所有使用该角色的 API 作业均受影响。正式部署需按其实际角色和业务启用面交由部署角色 ACL 维护方审核。本轮候选共享授权增量为零。

独立 PG16 使用本地迁移和 LIKE Activity 表保留类型、默认值和非空约束。夹具角色有 id 读回权。发起 INSERT 被拒 exit 1，补提议列后 INSERT RETURNING id exit 0，读取确认一行；UPDATE 被拒 exit 1；撤权后原 INSERT 再次被拒 exit 1，保留行数 1。实验限于一个 SQL 的权限检查，未复制外键和完整业务事务，不能据此保证发布、结算或公网 201。日志见 isolated-b.log，公网及现场投影见 chain-b.log、sql-b.log。

## A6 待确认：零认定和超过打卡跨度

现行负责人草稿接口允许认定 **0–999.99 小时、最多两位小数**，每次人工认定都必须填非空原因；计算值与认定值分开保留。它没有承接旧链“必须大于0、不能超过签到到签退跨度”的同一限制。代码依据是 `app-settlement-workbench.dto.ts` 的 `AppSettlementUpdateDraftItemDto` 数值约束和 `SettlementDraftService.updateItem`；旧依据是 `attendance-record.policy.ts:83–119` 及原集成验收`:1424,1442`。

零认定有合理用途：某人有到场事实，但最终应记缺席、请假或不计有效服务，仍需要保留这人的处理结果。人工值与计算值分开，也能处理机器记录不完整或实际休息与默认扣除不符的情况。风险是“缺证据”被悄悄当成0，或者只填一句理由就把1小时变成5小时，放大时长及后续资格。

建议确认以下口径后再实施：

- **允许有说明的零认定**，保留计算值、结果类型和理由；异常未处理、缺少必需来源的情况继续阻断，不用零认定绕过。例：机器算2小时，审核认定0，应看见“计算2、认定0及明确结果”，不能删掉记录。
- **有完整现场证据时，认定不得超过有效服务段总跨度**，按多个服务段合计，不只拿第一签到到最后签退的包围区间。例：9–10点和14–15点两段，不能因为首尾跨度6小时就认6小时。
- **超过机器计算值不一概等于越界**。例：完整现场跨度4小时，默认扣1小时休息算3小时；确有值守未休息的依据时，可按经批准的规则认4小时。要认5小时，应先补充可核验的现场事实，不能只加一个理由。
- **没有机器打卡的合法人工场景单独定补证/复核规则**，不能套一个“无跨度所以一律0”的校验。相应纠错/补证能力尚未交付时，应明确受阻，不声称仅靠现有原因文本就已支持。

这次决策针对历史验收中的手工结算小时；原生分类时长和政策型贡献仍沿各自冻结规则，不能借此自动改成同一口径。**待维护者确认上述建议；本文件没有改校验或旧负例。**

## A9 待确认：入队达标提醒

建议采用现有[事务候选](https://github.com/BA7IEE/srvf-nest-api/blob/89ec2a4aa/docs/handoff/v11-contribution-milestone-transaction-plan.md)的方向。它是开闸前必补能力，当前仍未接线，具体收据结构和最小数据库权限要在方案批准后审查。

| 问题 | 建议口径 |
| --- | --- |
| 什么时候提醒？ | 正式账本生效使申请人的有效积分从低于5到至少5时登记；仅审核通过或批次准备好不提醒。实际消息由提交后的 worker 发送。 |
| 提醒谁？ | 对应成员最新一条有效 joining 申请的申请人。按该申请轮次、既有北京日截止和封顶口径计算，不向全部活动成员或审核人群发。达到积分不等于已经完成入队。 |
| 再次跨线呢？ | 同一申请同一5分门槛只登记一次。4→5提醒；5→4不撤回已发消息；再4→5不另发。新申请独立计算，不能用旧申请的提醒冒充新申请完成。 |
| 两个活动同时把人推过5分？ | 复用既有人员锁，锁后计算提交前后值；数据库再用“申请+门槛”的唯一持久收据兜底。发生并发冲突须按既有整笔事务/幂等协议处理，不能吞异常当成功，也不改隔离级别或预算。 |
| 更正怎样处理？ | 按更正正式入账后的净分判定。4→6可以首次提醒；6→4不发达标提醒，页面仍显示真实4分。重复请求/成功重放不重复登记。更正期间仍显示旧分值，与 A7 一致。 |
| 中途失败呢？ | 账本、达标收据、通知意图放在同一事务；后续鉴权、审计等任一步失败，一起回滚，不出现“分没到账却已提醒”。提交响应丢失时先核对实际结果，不猜成失败后重复发送。 |
| 发不出去呢？ | 仍沿同一意图重试、告警和恢复。登记过不代表送达；保证一次持久意图不能冒充外部渠道绝对只投递一次。 |

持久收据不能只用可清理的 outbox 记录代替，否则清理后再次跨线可能重复提醒；也不能给客户端直接自填“已提醒”的权限。普通提交、worker、更正及 Human 路径都必须验证真实接线和最小权限，不能只测一条路径便宣布全部覆盖。

历史记录还需在开闸前核清：有可信旧意图/收据的可按审定规则接续；旧意图已清理、无法证明是否提醒过的，应标为待核实，由维护者决定迁移处理，不能自动当“从未提醒”批量补发。旧数据转换是否触发提醒也需单独确认。

**请维护者确认是否按上述方向实施 A9。** 批准前不新增收据表、不授数据库权限、不接消息生产者。以后验收须包括真实并发、门槛边界、跨轮次、清理后再跨线、故障回滚及失败投递恢复；本轮不恢复 #1430 已暂停的超时诊断。

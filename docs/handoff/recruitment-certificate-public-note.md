# 招新证书申报：公开审核说明

`PublicCertificateClaimDto.reviewNote` 仅在 `REJECTED`、`NEEDS_INFO` 返回本人需要处理的说明，其余状态返回 `null`，与公开进度的 `certificates[].note` 保持一致。

本人通过原微信／短信凭证、归属、锁后复核和版本校验撤回申报，仍得到 `WITHDRAWN`、新版本和申报计数。审核备注与审核人／时间继续保存在原记录中；不删除审核历史，不改变管理员敏感读权限、状态机、门槛重算或审计事务。

验收：真实 `withdrawPublic()` 回调配合内存事务，验证已批准申报撤回后不返回内部备注、内存存储模型保留审核历史、门槛及审计使用同一事务；六状态投影及归属／版本／终态拒绝回归。新增用例不连接数据库或外部 Provider，不能替代真实 HTTP／数据库证明。既有模块 HTTP／数据库回归与完整检查交本 PR 的隔离 CI；其通过不应被表述为新增撤回路径的数据库复现。

范围：仅公开备注投影、定向回归及必要生成摘要。未创建身份、权限、凭据或签链；不合并、不部署，不改生产配置。其他审查候选不在本次写集。

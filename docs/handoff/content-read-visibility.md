# 内容详情的可见性与 PV

公开和会员详情继续使用原有可见性规则、返回字段及 `CONTENT_NOT_FOUND`（404／29001）防枚举语义。详情在增加 PV 时，将同一调用者的 published、未删除和可见档条件放入原子 UPDATE；只投影该次符合条件的返回行。

管理员在首次读取之后将文章改为不可见并替换正文时，正在进行的旧读取返回原 404，不返回新私密正文、不进入附件投影，也不增加 PV。仍获准的公开或会员读取照常增加一次 PV；无关数据库错误继续向外传播。

没有新增接口、DTO、权限码、数据库对象或运行开关；列表及管理端写入流程不变。调用者的 App 资格和管理读取权限仍由既有逐请求解析提供，本次未改变该上下文的权限撤销协议。

回归包含匿名与非管理会员的内存屏障，以及既有公开内容 E2E 中的真实 HTTP／PostgreSQL等待：管理员更新事务保持行锁，观察本库 PV UPDATE 真实等待，再提交管理员更新，核对公开请求 404 与 PV 未增加。普通隔离 CI 的合成账号及库不等于生产身份验收；不需要真实 COS 或新增访问凭据。
